🎆 Diwali Message Generator
✨ Overview

This is a simple web application that generates personalized Diwali greetings. Users can enter their name, and the app returns a festive greeting message.

🚀 Features

User Input: Enter your text to get a Diwali greeting.

Generated Message: The app generates a greeting.

Interactive UI: Simple and easy-to-use interface with a “Generate Message” button.

🛠️ Technologies Used

Frontend: HTML, CSS, JavaScript, React.js

Backend: Node.js
